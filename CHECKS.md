# Результаты проверки

- Java 21: проект скомпилирован, интеграционный тест пройден (0 ошибок).
- Spring Boot запущен тестом на настоящем HTTP-порту с временной H2-базой.
- Проверены доступность HTML/CSS/JS без входа, вход трёх ролей, неверный пароль, отсутствие токена, неверный токен.
- Проверены создание, чтение, изменение контактов и удаление студента.
- Проверены создание, изменение email, ролей и пароля, вход с новым паролем, удаление пользователя.
- Проверено, что преподаватель не может создавать студентов, администратор не может управлять пользователями.
- Отдельная проверка JavaScript в DOM: вход, выход, поиск, обновление, открытие и закрытие карточки, отправка форм создания и изменения, удаление для ADMIN и SUPER_ADMIN; режим чтения для TEACHER. Эта проверка использовала подставные HTTP-ответы; реальные HTTP-запросы проверены интеграционным тестом выше.
- Синтаксис JavaScript проверен Node.js.

Ограничения: визуальная проверка в браузере и запуск Docker/PostgreSQL в этой среде не выполнялись. Интеграционный тест использует H2 только для проверки; основной проект и Docker настроены на PostgreSQL.
